# Mission 01 preview asset notes

This isolated preview bundles only the files it needs under `assets/` so the live root page remains unchanged.

- `assets/player/character-mobile.glb` and the eight FBX clips under `assets/animations/` are the existing Spellbound Ch08 character and its project animation files.
- `assets/enemies/UAL2_Standard.glb` is Quaternius Universal Animation Library 2 Standard, from https://quaternius.itch.io/universal-animation-library-2. The project animation archive manifest identifies this pack as part of its CC0 asset archive.
- Ch08 model textures are embedded in the GLB. The Quaternius GLB has no external image or buffer references. No separate texture files are needed.
